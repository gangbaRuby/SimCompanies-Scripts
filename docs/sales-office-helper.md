# 销售办公室优化（测试中）

## 功能与数据口径

设置入口为「销售办公室优化（测试中）」；开关键 `salesOfficeHelper` 沿用已注册备份的 `SC_PageActions_Settings`。默认开启，不新增独立持久化状态。

- **复制总需求**：当前大楼已完成寻单、尚未交付的全部订单，包含缺货和亏损订单；按资源合并，输出 `BUYING` 与 `:re-ID: x数量`。
- **复制缺货采购单**：先合并总需求，再按资源扣一次可用库存。可用库存来自游戏卡片，与游戏排除锁定库存后的结果一致，不从可能过期的仓库缓存重新计算。
- **集中交付**：固定面板分为盈利／持平和亏损两栏，各取页面顺序中的第一笔可交付订单。利润读取原生最终净利润，已包含品质加成、货物成本和寻单费用；原生 `(-) $0` 仍属于亏损。
- **用户点击**：只给原生按钮添加可移除的定位属性，以 CSS 固定到面板槽位。不移动 React 节点、不复制交付按钮、不调用 `.click()`、不自动提交，也不新增网络请求。游戏自己的交付仍由其原生事件处理。
- **交付中**：等待当前订单移除或原生错误反馈后再开放操作；错误显示在面板状态行，失败订单保留重试位置。慢请求期间不自动转到下一笔。

资源 ID 由已有 `SimcompaniesConstantsData.constantsResources` 中的图片名映射。货物无法识别时停用复制；同种资源在不同卡片中的可用库存尚未同步时暂时停用缺货复制，避免输出部分或错误清单。

## 调用链与清理

`src/index.js` 导入模块 → `pageObserver` 匹配 `/b/<id>/` → `SC_Modules.salesOfficeHelper.init()` → 扫描订单 DOM → 更新统计、固定原生按钮。

模块通过 `MutationObserver` 观察游戏 DOM 的卡片、净利润、禁用状态和错误反馈；通过 `ResizeObserver`、滚动与窗口尺寸事件更新固定槽位。重新初始化复用现有实例；切换建筑时排除尚未被 React 替换的旧卡片。离开建筑页或关闭开关调用 `destroy()`，断开 Observer、取消计时器和动画帧、移除监听、面板、样式及按钮定位属性。

有游戏弹窗时暂时隐藏面板、恢复原生按钮。遇到祖先 `transform` / `filter` / `contain` 或层叠遮挡导致无法准确定位时，恢复原订单按钮并显示说明。

## 游戏前端结构依据

2026-10-15 对照 `index-xSYKf8W7.js`：建筑类型 `B`；订单组件 `OCi`，货物汇总 `salesOfficeSummary`。组件常量名可能随构建改变，维护时需要重新核对。

| 用途 | 当前结构 |
| --- | --- |
| 已完成寻单的结算表 | `table.ebrfvjt2`；寻单中的卡片不渲染此表 |
| 财务区 | 表的父元素；同级控件容器为 `div.text-center` |
| 货物区域 | 财务区父行中的 `.ebrfvjt0` |
| 单资源需求 | `.ebrfvjt3` 的图片，以及 `.progress > span` 中未经格式化的 `可用库存/需求` |
| 最终净利润 | `tbody > tr:last-child > td[colspan="2"]`，负号为 `(-)` |
| 交付按钮 | 财务区 `:scope > div.text-center > button.btn-primary`；缺货时 disabled，提交中移除 |
| 原生错误 | 财务区 `.ebrfvjt6` |

这些 Emotion 组件 class 不是游戏公开 API。游戏更新后若结构不匹配，模块保守保留原按钮；应对照新前端修正选择器，不通过猜测发请求。

## 本地验证

执行 `npm run check` 完成构建。浏览器回归使用本机已有的 Playwright 与 Chrome，不加入生产依赖：确保 Node 能解析 `playwright`（可用 `NODE_PATH` 指向本机已有的 `node_modules`），然后运行：

```powershell
node --test tests/salesOfficeHelper.browser.cjs
```

`tests/fixtures/sales-office.html` 按上述结构模拟完成寻单、共享库存、禁用、成功、失败、品质变化和节点替换；所有页面和图片请求由测试本地响应，禁止脚本发起 fetch/XHR，不连接游戏服务器。输出截图位于 `dist/sales-office-check/`。

本地验证覆盖需求合并与缺货、剪贴板拒绝/缺失、原生真实点击逐笔交付、处理中锁定、错误重试、未知利润与负零、实际 `pageObserver` 路由分发、旧楼卡片隔离、开关清理、弹窗恢复、桌面/手机与深浅主题。

模拟页面不等于游戏实机：真实服务器交付、不同语言的金额显示、真实游戏浮层和移动导航仍需用户验证。窄屏面板默认留出底部 64px 与安全区，布局不可用时回退到原生按钮。
